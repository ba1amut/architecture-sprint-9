| КОД | Требования                                                                                                            |
|-----|-----------------------------------------------------------------------------------------------------------------------|
| F   | Функциональные (Functionality)                                                                                        |
| F1  | На сайте представлены актуальные депозиты с пбличными/общими ставками                                                 |
| F2  | Клиент может оставить заявку на депозит через сайт, указава ФИО и номер телефона                                      |
| F3  | Новые заявки с сайта храняться в всистеме колл-центра                                                                 |
| F4  | Оператор колл-центра имеет доступ к "новым" заявкам с сайта.                                                          |
| F5  | В интернет-банке предоставлены актуальные депозиты с персонализированными  ставками                                   |
| F6  | Интернет-банк позволяет подать заявку н аоткрытие счета                                                               |
| F7  | Ставки по депозитам храняться в АБС                                                                                   |
| F8  | АБС позволяет работать со ставками по депозитам сотрудникам депозитного и кредитного управлений                       |
| F9  | АБС позволяет работать с заявками по депозитам                                                                        |
| F10 | Клиент получает СМС-уведомления о подтверждения размера ставки и открытия депозита.                                   |
| U   | Удобство использования (Usability)                                                                                    |
| U1  | Интерфейс работы должен быть максимально удобным для клиента                                                          |
| U2  | Система дизайна для приложений должна придерживаться реализации которая принята в компании.                           |
| U3  | Пользователи при работе должны видеть привычные цвета и брендированные элементы                                       |
| R   | Надёжность (Reliability)                                                                                              |
| R1  | предусмотреть равномерное горизонтальное масштабирование и распределение запросов между серверами, приложениями и ЦОД |
| R2  | все сервисы должны работать 24/7 и быть доступны в 99,9% случаев                                                      |
| R3  | в случае сбоев в ЦОД необходимо, чтобы сервисы интернет-банка были доступны и выдерживали требуемую нагрузку          |
| P   | Производительность (Performance)                                                                                      |
| P1  | Отклик по всем операциям должен быть максимально быстрым и занимать миллисекунды                                      |
| S   | Поддерживаемость (Supportability)                                                                                     |
| S1  | При доработках во всех системах нужно как можно больше использовать технологии, которые уже есть в банке              |
| S2  | Новые технологии должны быть совместимы с существующими платформами разработки                                        |
| S3  | Необходимо обеспечить на стороне банка экспертизу реализуемых решений.                                                |
| +R   |  + Ограничения (Restrictions)                                                                                         |
| +R1  | Необходимо предусмотреть передачу чуствительных данных                                                                |
| +R2  | Доступ к данных депозитов и кредитов доложны быть разделены                                                           |
